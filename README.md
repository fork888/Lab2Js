# Reflection Questions

## 1. How did array methods like `push()` and `filter()` help you manipulate data in this activity?

`push()` helped me add items to my shopping list. `filter()` helped me look through the list and find items that matched what I searched for. They made working with the array a lot easier.

## 2. What challenges did you face when trying to filter and search for items in the array?

The hardest part was making sure the search worked correctly. I had to make sure it could find items even if they were typed differently, like using capital letters or lowercase letters.

## 3. How would you modify this code to make it more efficient or user-friendly?

I would add a search box so users can search for items on the page. I would also add a way to remove specific items instead of just the last item. I think that would make the shopping list easier to use.
